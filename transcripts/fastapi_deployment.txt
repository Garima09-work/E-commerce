3. ARCHITECTURE & SECURITY BOUNDARY
--------------------------------------------------------------------------------
The service layer serves strictly as a thin transport layer:
  HTTP Client Request
  ↓
  FastAPI Request Validation (Pydantic models with extra="forbid")
  ↓
  run_agent(query_text, thread_id)
  ↓
  Input Guardrails Node (PII masking + prompt injection detection)
  ↓
  Router Node (intent classification: policy vs order)
  ↓
  Tool Execution Node (policy RAG or check_order_status validated via OrderStatusResult)
  ↓
  Output Guardrails Node (grounding similarity verification + AgentResponse Pydantic validation)
  ↓
  SQLite Checkpointer (sanitized thread-isolated persistence)
  ↓
  FastAPI HTTP Response (validated AgentResponse)

Zero business logic, routing logic, or tool invocations are duplicated in FastAPI.
