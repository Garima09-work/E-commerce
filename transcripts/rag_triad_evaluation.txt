3. IMPLEMENTATION ARCHITECTURE (eval/rag_triad.py)
--------------------------------------------------------------------------------
- Component: eval/rag_triad.py
- Reuses existing NykaaAssist RAG pipeline (retrieve_context and generate_grounded_answer) rather than creating a duplicate pipeline.
- Scoring Methodology:
  1. Context Relevance:
     - Measures alignment between retrieved chunks and expected source documents.
     - Formula: 0.60 * (matching_chunks_ratio) + 0.40 * min(1.0, mean_similarity / 0.70).
     - Threshold: >= 0.50.
  2. Groundedness:
     - Measures claim-level factual support of generated answer against retrieved context chunks.
     - Extracts non-stopword tokens and sub-phrase matches per sentence.
     - Unsupported claims are recorded with exact string evidence in the audit log.
     - Safe fallback responses receive 1.0 (zero unsupported factual claims).
     - Threshold: >= 0.90.
  3. Answer Relevance:
     - Measures semantic and lexical alignment between customer query and generated answer.
     - Formula: 0.60 * cosine_similarity(query_emb, answer_emb) + 0.40 * keyword_recall.
     - Out-of-scope safe fallbacks are scored as 1.0 (correct refusal).
     - Threshold: >= 0.60.
  4. Overall RAG-Triad Score:
     - Simple arithmetic mean of (CR + G + AR) / 3.0.
     - Threshold: >= 0.70.
- Outputs:
  - Human-readable ASCII table scorecard.
  - JSON-compatible structured export: eval/rag_triad_results.json.
