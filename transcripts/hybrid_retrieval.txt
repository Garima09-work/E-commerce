                        Reciprocal Rank Fusion (RRF)
                        - k_rrf = 60

                            3. Chunk ID string (ascending)
                        - Top-k (k=3) merged chunks selected
                                      │

                        - Cosine similarity with query embedding

                        - Default threshold: 0.35 (strictly enforced)

                        - Fallback response if confidence < 0.35

2. COMPONENT DETAILS
================================================================================
A. Pure-Python Okapi BM25 (`rag/lexical.py`):
  - Pure Python implementation with zero external dependencies (no rank-bm25, no nltk).
  - Formula:
      IDF(qi) = ln((N - n(qi) + 0.5) / (n(qi) + 0.5) + 1.0)
      TF_norm(qi, D) = (f(qi, D) * (k1 + 1)) / (f(qi, D) + k1 * (1 - b + b * (|D| / avgdl)))
      Score(D, Q) = sum(IDF(qi) * TF_norm(qi, D))
  - Hyperparameters: k1 = 1.5, b = 0.75.
  - Corpus: Loaded directly from ChromaDB `policy_chunks_sentence` collection (18 chunks across 10 documents).
  - Tokenization: Lowercase regex `\b[a-z0-9_]+\b` with a 45-term English stopword list.
  - Caching: In-memory singleton `_CACHED_BM25_INDEX` avoids re-tokenization across queries.

B. Reciprocal Rank Fusion (`rag/hybrid.py`):
  - Canonical formula: RRF_score(d) = sum_{m in M} 1 / (k_rrf + rank_m(d))
  - RRF constant: k_rrf = 60.
  - Candidate retrieval depth: candidate_k = 10 from each modality.
  - Dot-Product Semantic Similarity Preservation:
      For chunks retrieved via BM25 not in the top vector results, their cosine
      similarity is computed against the query embedding using cached normalized
      chunk embeddings. This ensures confidence calibration remains 100% accurate.
  - Deterministic tie-breaking: (-round(rrf_score, 6), -round(sim, 4), chunk_id).

C. Grounded Generation Integration (`rag/generate.py`):
  - Added parameter `mode: Optional[str] = None` to `retrieve_context` and `generate_grounded_answer`.
  - Resolution: `mode or os.environ.get("RETRIEVAL_MODE", "hybrid")`.
  - Default is `mode="hybrid"`: live agent traffic immediately benefits from hybrid search.
  - Preserves `mode="semantic"` for baseline comparisons and regression verification.
  - Grounding confidence threshold 0.35 and fallback message strictly preserved.
