2. FINAL PYDANTIC SCHEMA
--------------------------------------------------------------------------------
Schema strictly implements TRD.md §3.3 with Pydantic v2:

class ResponseType(str, Enum):
    POLICY_ANSWER = "policy_answer"
    ORDER_STATUS = "order_status"
    FALLBACK = "fallback"
    GUARDRAIL_BLOCK = "guardrail_block"

class OrderStatus(str, Enum):
    PLACED = "Placed"
    SHIPPED = "Shipped"
    DELIVERED = "Delivered"
    RETURNED = "Returned"
    REFUNDED = "Refunded"
    NOT_FOUND = "Not Found"

class OrderStatusResult(BaseModel):
    model_config = ConfigDict(extra="forbid")
    record_id: str = Field(pattern=r"^NYK-\d{5}$")
    status: OrderStatus
    order_value_inr: Optional[float] = Field(default=None, ge=0.0)
    escalation_score: Optional[float] = Field(default=None, ge=0.0, le=1.0)
    error: Optional[str] = None

class AgentResponse(BaseModel):
    model_config = ConfigDict(extra="forbid")
    response_type: ResponseType
    answer: str = Field(min_length=1)
    sources: List[str]
    confidence: float = Field(ge=0.0, le=1.0)
    escalation_score: Optional[float] = Field(default=None, ge=0.0, le=1.0)
    trace_id: str = Field(min_length=1)

    @field_validator("answer")
    def validate_answer_not_blank(cls, val: str) -> str:
        if not val.strip():
            raise ValueError("Answer cannot be empty or whitespace only")
        return val

    @field_validator("sources")
    def validate_sources(cls, val: List[str]) -> List[str]:
        for item in val:
            if not isinstance(item, str) or not item.strip():
                raise ValueError("Sources must be non-empty strings")
        return val

    @field_validator("trace_id")
    def validate_trace_id(cls, val: str) -> str:
        if not val.strip():
            raise ValueError("Trace ID cannot be empty or whitespace only")
        return val

3. RESPONSE TYPES COVERED
--------------------------------------------------------------------------------
Every customer-facing path is mapped to one of 4 declared ResponseType enums:
1. policy_answer : Grounded answers retrieved from KB (confidence >= 0.35, sources populated).
2. order_status  : Deterministic order status lookups (placed, shipped, delivered, returned, refunded, or not found).
3. fallback      : Unambiguous fallback on low retrieval similarity (< 0.35) or out-of-scope queries.
4. guardrail_block: Immediate refusal on prompt injection attacks (0 tools, zero SQLite checkpoints).

4. VALIDATION BOUNDARY & EXECUTION PIPELINE
--------------------------------------------------------------------------------
The execution pipeline guarantees that every response leaving the StateGraph is validated:
  User Query
  ↓
  Input Guardrails Node (PII mask + prompt injection detection)
  ↓
  Router Node (intent classification: policy vs order)
  ↓
  Tool Nodes (policy RAG or check_order_status validated via OrderStatusResult)
  ↓
  Output Guardrails Node:
    - validate_output_groundedness (threshold check + PII masking)
    - Pydantic validation via AgentResponse.model_validate()
    - SPY_VALIDATED_RESPONSES interceptor captures validated instance
    - validated_model.model_dump() serialization
  ↓
  SQLite Checkpointer (sanitized state persistence)
  ↓
  Customer Response

Spy verification proves that 100% of customer responses in run_agent() passed through this boundary.
Zero paths bypass the Pydantic schema validation layer.

5. FAIL-CLOSED BEHAVIOR
--------------------------------------------------------------------------------
When invalid or corrupted state is received:
- validate_agent_response() catches the ValidationError.
- It independently constructs a fresh, clean AgentResponse fallback:
    response_type    = ResponseType.FALLBACK
    answer           = FALLBACK_RESPONSE
    sources          = []
    confidence       = 0.0
    escalation_score = None
    trace_id         = sanitized safe_trace_id
- Never copies or reuses corrupted answers, poison tokens, malformed sources, or unexpected fields.
- Verified: Injecting a corrupted state with poison token "POISON_LEAK_ATTEMPT" resulted in:
    * response_type: fallback
    * answer: "I don't have enough grounded information..." (clean fallback)
    * sources: []
    * confidence: 0.0
    * "POISON_LEAK_ATTEMPT" absent from answer.
    * Extra fields completely dropped.
