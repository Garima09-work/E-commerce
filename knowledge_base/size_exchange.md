# Size Exchange Policy

Customers may request a one-time free size exchange for Apparel and Footwear products within 7 days of package delivery. Size exchange requests are subject to replacement inventory availability in the requested variant size at the designated warehouse. If the desired replacement size is out of stock, a standard return is processed, and the full order value is refunded to the original payment method. Exchanged items must remain unused, unwashed, odor-free, and returned with all original tags and shoe boxes intact.
